# 造作画布 ZZHB

造作画布是一款面向设计工作流的本地 AI 画布。完全免费，支持自定义API，为了方便不愿意折腾的新手，也内置了两个中转商。

你可以在同一个项目里整理参考图、提示词、模型结果、对话记录和设计说明，再把它们连接成可以持续修改的工作流程。

本仓库只用于发布 Windows 可执行版本和公开使用说明。

## 0.1.2 更新内容

本次更新新增了多种实用节点与工作流能力，并进一步优化了画布使用体验。

### 新增功能

1. **对话节点**  
   支持像网页端一样与 AI 进行多轮对话，方便持续迭代提示词、完善创作思路。

2. **图像拼接与裁剪节点**  
   可以将多张图片拼接到同一画布中，帮助生成内容更加一致的图像。配合裁剪节点，还能按照原始拼接布局，将生成结果自动裁剪为多张独立图片。

3. **便签节点**  
   支持直接在画布中添加注释，方便记录灵感、说明和待办事项。

4. **模板功能**  
   新增三个方便新手入门的官方模板：

   - 草图渲染
   - 区域编辑
   - 提示词反推

   你也可以将自己的工作流保存为模板，方便以后快速复用。

5. **提示词预设**  
   可以将常用提示词保存为预设，并在对话节点或文本节点中直接调用，无需反复复制粘贴。

6. **ComfyUI 工作流支持**  
   支持将 ComfyUI 工作流导入画布，并直接在画布中调用。

7. **图像对比节点**  
   支持连接两张图片，通过滑块或并排模式快速对比图像差异。

### 体验优化

- 优化了画布的操作流畅度与交互体验。

## 下载与启动

1. 前往 [Releases](https://github.com/yangwc18181/zaozuohuabu-windows-preview/releases/latest)。
2. 下载 最新版画布。
3. 完整解压 ZIP，不要直接在压缩包里运行。
4. 双击 `ZZHB.exe`，等待本地服务启动并自动打开浏览器。
5. 运行需要保持ZZHB.exe在后台运行，不要关闭黑色的命令框。

当前版本支持 Windows x64。由于尚未购买代码签名，Windows 可能显示“未知发布者”，请确认文件来自本仓库后再运行。

## 第一次使用

首次进入后，打开“模型与供应商”：

- 当前模型和供应商连接已经预设完成。
- 只需在准备使用的供应商处填写自己的 API Key，无需手动填写 Base URL、协议或模型编号。
- 软件包不包含开发者或其他用户的 Key。
- ComfyUI 工作流需要你的电脑或者云端已安装并启动对应的本地 ComfyUI 服务。

模型调用可能产生费用。使用任何官方或第三方供应商前，请先确认价格、额度、隐私政策和服务条款，建议先进行少量测试。

## 0.1.1 更新

- 长便签在未选中状态下也保持固定高度和内部滚动，不再向下铺开全部内容。

## 0.1.1 包含什么

- 25 条可选择的模型目录，以及 27 条已经关联好的供应商调用配置；所有 Key 均为空。
- 3 份 ComfyUI 工作流：白膜参考参考图、草图渲染、高清放大。
- 3 个首页官方模板：草图渲染、指示框改图、提示词反推。
- 普通文本节点和独立对话节点。
- 图片节点、便签节点、画布连接、项目保存与历史内容恢复。
- 模型预设、工作流和画布模板的本地导入导出能力。
